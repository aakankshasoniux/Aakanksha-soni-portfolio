# Aakanksha Soni — Portfolio

Portfolio website showcasing web design work for the City of Santa Clara Department of Parks & Recreation.

## Structure

- `index.html` — page markup
- `css/style.css` — styles
- `js/script.js` — project data + gallery/lightbox behavior
- `images/` — project screenshots

## Running locally

No build step required. From this folder:

```bash
python -m http.server 8080
```

Then open http://localhost:8080 in a browser.
